# 🚂 寶島鐵道大亨

搭火車環島、買下全台名產，成為台灣第一的鐵道大亨！

一款以台灣鐵路為舞台的原創大富翁類桌遊網頁遊戲，支援 1～4 人同機輪流遊玩或與電腦對戰。

## 玩法

- 擲骰子沿鐵路前進，第一個抵達 🚩 目的地的人可以拿到獎金
- 停在車站可以購買在地物件，每年 3 月決算收益；買下同一站全部物件即可「獨佔」，收益加倍
- 藍色格拿錢、紅色格扣錢、黃色格抽卡片
- 小心 🌧️ 衰尾道人！碰到其他玩家就能把它甩掉
- 遊戲年數結束時，總資產最多的人獲勝

## 線上對戰

1. 房主在開始畫面選「🌐 線上對戰」→「建立房間」，會得到 4 碼房間代碼
2. 朋友打開遊戲（或房主分享的連結），輸入名字與代碼加入
3. 人數不夠可以加入電腦玩家，房主按「開始遊戲」

房主的瀏覽器負責執行遊戲，請保持房主頁面開著。玩家斷線時會由電腦代打，回來後（或用同樣名字重新加入）就能接手。
連線使用 [PeerJS](https://peerjs.com/)（WebRTC 點對點），不需要自己的伺服器。

## 本機執行

純 HTML / CSS / JavaScript，不需要建置：

```bash
python -m http.server 8741
```

然後打開 http://localhost:8741

## 檔案結構

- `index.html` — 頁面
- `css/style.css` — 樣式
- `js/data.js` — 車站、路線、物件、卡片資料
- `js/game.js` — 遊戲引擎與介面
